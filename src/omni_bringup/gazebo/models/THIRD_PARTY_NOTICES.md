# Third-party Gazebo arena assets

The following directories contain arena meshes copied from
`SMBU-PolarBear-Robotics-Team/rmu_gazebo_simulator` at commit
`36e3cf423448cbef12fa2c56f61f81eade8e286d`:

- `rmuc_2024`
- `rmuc_2025`
- `rmul_2024`
- `rmul_2025`

Upstream project:
<https://github.com/SMBU-PolarBear-Robotics-Team/rmu_gazebo_simulator>

The upstream project is distributed under Apache License 2.0. A copy is
stored in `rmu_gazebo_simulator_LICENSE`. The mesh and texture files are
kept unchanged. Harmonic world integration and the local robot / sensor
model are maintained by this project and do not depend on the upstream ROS
packages or Gazebo plugins.
